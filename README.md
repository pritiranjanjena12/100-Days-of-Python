## 📌 Daily Workflow

For each day, I will:

1. Learn the day's concepts.
2. Solve one meaningful coding problem or build a practical feature.
3. Write and understand the code myself.
4. Test the program with different inputs.
5. Debug and fix any errors.
6. Save the work in the appropriate repository file.
7. Commit the changes with a clear Git commit message.
8. Push the changes to GitHub.
9. Update this README checklist after verifying the work.
